## What is locally ready

Preparation accepts existing HFT or works without it, including canonical
fallback when an ayah bundle is absent. The simplified reader prompt asks for
a connected reading brief. Its source pointers retrieve whole original chains,
lexical evidence and Quranic passages for the writer. A direct-writer prompt
can instead use the broader evidence. These are source handoffs, not semantic
quality guarantees. There is no automated runner or test suite in v10.

A local run of the revised preparation produced the reader prompt and then a
writer prompt using a Markdown conversion of the historical map. All 16
selected source readings matched their originals; the clay passages and all
rare usage panels survived. The writer prompt measured 303,187 bytes. This
checked source transport and made no model calls; it did not evaluate the new
reader prompt or repair the historical interpretation.

The next useful model work is prose on a small, shared evidence sample. First
establish whether the synthesis reaches the desired quality; then compare
reduction and total cost. Long-surah efficiency and discovery without upstream
interpretation remain open. No production run should be inferred from this
preparation work.
