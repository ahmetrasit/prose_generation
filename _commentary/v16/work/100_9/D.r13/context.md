# 100:9 — focus

۞ أَفَلَا يَعْلَمُ إِذَا بُعْثِرَ مَا فِى ٱلْقُبُورِ

Anchor translation (canonical reading, reference only):

Öyleyse bilmez mi ki mezarlarda olanlar dışarı çıkarıldığında,
