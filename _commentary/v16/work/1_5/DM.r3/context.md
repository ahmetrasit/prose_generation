# 1:5 — focus

إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ

Anchor translation (canonical reading, reference only):

Yalnız sana kulluk ederiz ve yalnız senden yardım isteriz.
