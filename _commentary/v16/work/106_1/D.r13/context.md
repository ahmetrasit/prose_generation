# Surah 106 — full text (context; no pericope)

- 106:1 ◀ focus لِإِيلَٰفِ قُرَيْشٍ

- 106:4 ٱلَّذِىٓ أَطْعَمَهُم مِّن جُوعٍۢ وَءَامَنَهُم مِّنْ خَوْفٍۭ
