# 106:4 — focus

ٱلَّذِىٓ أَطْعَمَهُم مِّن جُوعٍۢ وَءَامَنَهُم مِّنْ خَوْفٍۭ

Anchor translation (canonical reading, reference only):

O, onları açlıktan doyurdu ve korkudan güvene kavuşturdu.
