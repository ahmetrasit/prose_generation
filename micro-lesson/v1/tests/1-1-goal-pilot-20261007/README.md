# 1:1 goal pilot: Haiku, Sonnet and Opus 5.5

First trial of [GOAL.md](../../../GOAL.md) as the authoring brief. One agent per
model writes lessons for 1:1 p01–p04 from the same [packet](packet.md), in a
single context, with no engines, assembly or review. Ontology annotations,
prerequisites and the JSON contract are left out to keep attention on whether
the lessons teach.

- `haiku/lessons.md`: Haiku 5.5, user-selected for this rerun.
- `sonnet/lessons.md`: Sonnet 5.5, run in parallel for comparison.
- `opus/lessons.md`: Opus 5.5, run in parallel for comparison.
