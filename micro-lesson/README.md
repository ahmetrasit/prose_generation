# Micro-lessons

Short Turkish lessons attached to paragraphs of ayah and surah commentary. Three
linguistic perspectives discover grammar, root/form semantics and Turkish mapping
opportunities. Each coherent lesson can carry several ontology annotations from
any categories. Ranking controls display, not discovery; commentary stays unchanged.

Start with [v1/README.md](v1/README.md), [v1/RUNBOOK.md](v1/RUNBOOK.md), and the
[v1 ontology guide](v1/ONTOLOGY.md). The authored reading curriculum has 297 concepts,
30 overlapping topics and seven routes in 33 teaching modules. Branch-specific
Turkish glosses and error profiles come from the sibling dictionary repository.

The workflow consists of prompts, shared content contracts, a complete scoped
catalog, and worked examples. It has no runner, hashes, validation stages, or
model orchestration, and is independent of the commentary enrichment version.
