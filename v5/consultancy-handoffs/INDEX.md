# CDBX Series — Consultancy Gap Mitigation Handoffs

**Date:** 2026-09-10
**Purpose:** Each handoff identifies what transfers directly from the teaching book to consultancy use, what gaps remain, and what deliverables/templates to develop to close them.

---

## Series consultancy architecture

The six books form a consultancy toolkit when supplemented with the deliverables identified in each handoff:

| Book | Teaching role | Consultancy role | Primary gap type |
|---|---|---|---|
| **1A** | Software/AI reviewer training | Software submission readiness audit + remediation | Evaluation → remediation templates |
| **1B** | Cybersecurity reviewer training | Security assessment + architecture advisory | Evaluation → design templates |
| **1C** | Validation methods (entry point) | Validation protocol authoring + study design | Evaluation → protocol authoring |
| **1D** | AI/ML device development | AI/ML development advisory + PCCP authoring | Build artifacts already exist; need client-facing wrappers |
| **2** | EU IVDR assessment | EU regulatory strategy + technical documentation | Assessment → documentation authoring |
| **3** | Consulting practice | Engagement delivery + practice operations | Methodology exists; needs technical toolkit routing |

## Cross-cutting gaps (affect all books)

1. **Client-facing report format.** Every book teaches how to reach conclusions but none teaches how to present findings to a client. A universal consultancy report template (executive summary → prioritized findings → remediation roadmap → timeline) should be developed once and used across all engagement types. Owned by Book 3, sourced by all.

2. **Remediation prioritization framework.** The triage matrix (regulatory risk × remediation cost × dependency) applies to every engagement type. Develop once in Book 1A (where the 91-item checklist makes the worked example clearest), reference from all other books.

3. **Engagement economics integration.** Book 3 Ch. 5 teaches consulting economics in general. Each engagement playbook needs specific pricing guidance: typical scope, hours, rate positioning, and margin expectations for that engagement type.

4. **Regulatory currency maintenance.** Every book references standards and guidances that update. A consultancy practice needs a currency-monitoring SOP: which sources to watch, review cadence, impact assessment process, client notification threshold. Owned by Book 3 (practice operations), informed by all technical books.
