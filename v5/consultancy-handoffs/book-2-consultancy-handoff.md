# Book 2 Consultancy Handoff

**Book:** CDBX Book 2 — EU IVDR Evidence and Lifecycle Assessment for Computational and Molecular Diagnostics
**Scope:** 17 chapters. EU regulatory system, IVDR classification, conformity assessment, GSPRs, technical documentation, performance evaluation, companion diagnostics, MDSW/AI Act/cybersecurity, PMS/vigilance, US-EU reuse.
**Current strength:** Assessor-level EU evidence integration. The book teaches how a notified body or competent authority evaluates a diagnostic device dossier under IVDR — which is exactly what a consultant needs to understand to prepare one.

---

## What transfers directly to consultancy

1. **IVDR classification reasoning (Ch. 3).** Directly usable for classification consultancy — the highest-volume EU regulatory engagement type.
2. **Conformity assessment route selection (Ch. 4).** Consultants advise clients on which conformity route to pursue; this chapter teaches the decision logic.
3. **GSPR compliance strategy (Ch. 5).** General safety and performance requirements mapping is a standard consultancy deliverable.
4. **Performance evaluation planning (Ch. 7).** The prospective evidence plan and sufficiency logic are directly usable for writing PEP documents.
5. **US-EU evidence reuse (Ch. 16).** Dual-jurisdiction consultancy is the premium engagement; this chapter provides the reuse framework.
6. **Assessor flight check (Ch. 17).** Run it as a pre-submission readiness audit from the assessor's perspective.

## Gaps to close for consultancy use

### Gap 1: EU technical documentation authoring

**What the book teaches:** How an assessor evaluates technical documentation (Ch. 6).
**What a consultant needs:** How to structure and write technical documentation that satisfies the assessor.

**Mitigation — add IVDR technical documentation templates:**

| IVDR Annex | Template to develop |
|---|---|
| Annex II — Technical documentation | Master technical documentation structure template with section-by-section content guidance, minimum evidence per section, common deficiency patterns from notified body audits |
| Annex III — Technical documentation on PMS | PMS plan template, PMS report template, PSUR template with specific content for computational/molecular diagnostics |
| Annex XIII — Performance evaluation | Performance evaluation plan (PEP) template, performance evaluation report (PER) template, scientific validity report template, analytical performance study report template, clinical performance study report template |
| Annex XIV — Performance studies | Clinical performance study application template, protocol template compliant with Annex XIV requirements, informed consent framework |

### Gap 2: Notified body interaction strategy

**What the book teaches:** How the conformity assessment works from the assessor's side.
**What a consultant needs:** How to manage the manufacturer-NB relationship.

**Mitigation:**

- Notified body selection guide: criteria for selecting an NB for computational/molecular diagnostics, capacity assessment, specialization matching
- NB audit preparation playbook: common audit focus areas for IVD software and AI, documentation readiness checklist, personnel preparation, CAPA-readiness for findings
- Deficiency response template: structured response format for NB observations, with evidence attachment guidance and timeline management
- NB opinion request strategy for Class D devices: when to request, what to include, how to manage the timeline against the designation timeline

### Gap 3: IVDR transition consultancy

**What the book teaches:** The steady-state IVDR requirements.
**What a consultant needs:** How to manage the IVDD-to-IVDR transition for legacy devices still in the market.

**Mitigation:**

- Legacy device gap assessment template: IVDD compliance baseline → IVDR delta requirements → gap inventory → remediation plan → timeline to compliance deadline
- Classification migration guide: how devices classified under IVDD map to IVDR risk classes, with specific attention to software/AI devices that may reclassify upward
- Performance evaluation evidence gap analysis: what existing clinical data can be reused vs. what new studies are needed under IVDR performance evaluation requirements
- Transition timeline planning tool: mapping device portfolio against IVDR transition deadlines, NB capacity, and study timelines

### Gap 4: Product-level execution gap

**The curriculum gap audit notes:** Book 2 recognizes controlled product configurations but does not teach how components are developed or transferred.

**Mitigation for consultancy:**

- EU-specific design and development file structure template: mapping ISO 13485 design controls to IVDR technical documentation requirements
- Manufacturer QMS gap assessment template: ISO 13485 baseline → IVDR-specific requirements → gap inventory (focus on software lifecycle, AI/ML, cybersecurity, clinical evidence management)
- This routes to Book 1D for AI/ML development specifics and to Book 1A/1B for software/cybersecurity specifics — the consultancy deliverable here is the EU assessment wrapper around those technical foundations

### Gap 5: Companion diagnostic EU consultancy

**What the book teaches:** CDx program strategy and IVDR program logic (Ch. 13).
**What a consultant needs:** Operational CDx development program management for EU.

**Mitigation:**

- EU CDx regulatory strategy template: drug-diagnostic co-development timeline, common specification applicability, consultation with competent authority, coordination with EMA scientific advice
- CDx performance evaluation strategy: bridging from drug trial data to standalone analytical/clinical performance claims
- CDx labeling coordination template: IVD labeling ↔ medicinal product SmPC cross-referencing
- Multi-jurisdiction CDx strategy: FDA-EU parallel development planning, evidence reuse strategy, timeline synchronization
