# Ayah recitation

Prepare one joined TTS request per ayah with commentary:

`<Turkish surah name> <ayah number>: <canonical Arabic ayah text>`

Example: `Fatiha 5: إِيَّاكَ نَعْبُدُ وَإِيَّاكَ نَسْتَعِينُ`

Arabic text comes from the canonical Quran text source. This collection is
separate from commentary audio; no audio has been generated yet.
