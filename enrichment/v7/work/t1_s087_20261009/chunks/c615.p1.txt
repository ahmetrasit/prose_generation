روا بعد سبع سنين فقال: { أولم يعلموا أن الله يبسط } يعنى يوسع { الرزق لمن يشآء ويقدر } يعنى ويقتر على من يشاء { إن في ذلك لآيات } يعنى لعلامات { لقوم يؤمنون } [آية: 52] يعنى يصدقون بتوحيد الله عز وجل.
{ قل يعبادي الذين أسرفوا على أنفسهم } نزلت فى مشركى مكة وذلك أن الله عز وجل أنزل فى الفرقان:
والذين لا يدعون مع الله إلها آخر
[الآية: 68] فقال وحشى، مولى المطعم بن عدى بن نوفل: إنى قد فعلت هذه الخصال فكيف لى بالتوبة فنزل فيه:
إلا من تاب وآمن وعمل عملا صالحا فأولئك يبدل الله سيئاتهم حسنات وكان الله غفورا رحيما
[الفرقان: 70] فأسلم وحشى، فقال مشركو مكة قد قبل من وحشى توبته، وقد نزل فيه ولم ينزل فينا فنزلت فى مشركى مكة: { يعبادي الذين أسرفوا على أنفسهم } يعنى بالإسراف: الشرك والقتل والزنا فلا ذنب أعظم إسرافا من الشرك { لا تقنطوا } يقول: لا تيأسوا { من رحمة الله } لأنهم ظنوا ألا توبة لهم { إن الله يغفر الذنوب جميعا } يعنى الشرك والقتل والزنا الذى ذكر فى سورة الفرقان { إنه هو الغفور الرحيم } [آية: 53] لمن تاب منها ثم دعاهم إلى التوبة.
فقال سبحانه: { وأنيبوا إلى ربكم } يقول: وارجعوا من الذنوب إلى الله { وأسلموا له } يعنى وأخلصوا له بالتوحيد، ثم خوفهم فقال: { من قبل أن يأتيكم العذاب ثم لا تنصرون } [آية: 54] يعنى لا تمنعون من العذاب.

ثم ذكر النعم، فقال تعالى: { الله الذي جعل لكم الليل لتسكنوا فيه والنهار مبصرا } لابتغاء الرزق، فهذا فضله، فذلك قوله سبحانه: { إن الله لذو فضل على الناس } يعنى كفار مكة { ولكن أكثر الناس لا يشكرون } [آية: 61] ربهم فى نعمه فيوحدونه.
