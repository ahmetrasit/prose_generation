Reading groups

The hybrid workflow reads by group: one small agent unit per group and surah (or ayah), so every source is read without any one agent carrying the whole corpus. ayah: segments tied to the ayah. root: lexicon entries of the ayah's roots. search: hits of scripted searches. cites: segments that cite the ayah. Required groups must be heard on every page.
