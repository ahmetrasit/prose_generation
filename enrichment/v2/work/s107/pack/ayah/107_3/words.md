# 107:3 — words and the elements a faithful translation must carry

وَلَا يَحُضُّ عَلَىٰ طَعَامِ ٱلْمِسْكِينِ

Per word: QAC morphemes with their features in plain terms. These are the checks for the meal review: a translation keeps, drops or substitutes each element (a preposition, an attached pronoun, number, definiteness, voice, emphasis, a conjunction). Turkish may force a change; say so when it does.

## w1 وَلَا  (107:3:1; lemma لَا; root —)
- وَ: wa- (and)
- لَا: negation

## w2 يَحُضُّ  (107:3:2; lemma يَحُضُّ; root ح ض ض)
- يَحُضُّ: verb; imperfect (ongoing/future); 3rd person masc. singular

## w3 عَلَىٰ  (107:3:3; lemma عَلَىٰ; root —)
- عَلَىٰ: preposition

## w4 طَعَامِ  (107:3:4; lemma طَعَام; root ط ع م)
- طَعَامِ: noun; M; genitive

## w5 ٱلْمِسْكِينِ  (107:3:5; lemma مِسْكِين; root س ك ن)
- ٱلْ: al- (definite article; Turkish has none — definiteness must be carried otherwise or is lost)
- مِسْكِينِ: noun; masc. singular; genitive
