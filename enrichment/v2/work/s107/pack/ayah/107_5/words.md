# 107:5 — words and the elements a faithful translation must carry

ٱلَّذِينَ هُمْ عَن صَلَاتِهِمْ سَاهُونَ

Per word: QAC morphemes with their features in plain terms. These are the checks for the meal review: a translation keeps, drops or substitutes each element (a preposition, an attached pronoun, number, definiteness, voice, emphasis, a conjunction). Turkish may force a change; say so when it does.

## w1 ٱلَّذِينَ  (107:5:1; lemma ٱلَّذِى; root —)
- ٱلَّذِينَ: relative pronoun; masc. PLURAL

## w2 هُمْ  (107:5:2; lemma —; root —)
- هُمْ: pronoun; 3rd person masc. PLURAL

## w3 عَن  (107:5:3; lemma عَن; root —)
- عَن: preposition

## w4 صَلَاتِهِمْ  (107:5:4; lemma صَلَوٰة; root ص ل و)
- صَلَاتِ: noun; F; genitive
- هِمْ: attached pronoun 3MP = their/them (m.pl.)

## w5 سَاهُونَ  (107:5:5; lemma سَاهُون; root س ه و)
- سَاهُونَ: noun; ACT; PCPL; masc. PLURAL; nominative
