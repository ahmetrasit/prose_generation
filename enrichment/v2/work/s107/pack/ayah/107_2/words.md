# 107:2 — words and the elements a faithful translation must carry

فَذَٰلِكَ ٱلَّذِى يَدُعُّ ٱلْيَتِيمَ

Per word: QAC morphemes with their features in plain terms. These are the checks for the meal review: a translation keeps, drops or substitutes each element (a preposition, an attached pronoun, number, definiteness, voice, emphasis, a conjunction). Turkish may force a change; say so when it does.

## w1 فَذَٰلِكَ  (107:2:1; lemma ذَٰلِك; root —)
- فَ: fa- (and so / then)
- ذَٰلِكَ: demonstrative; masc. singular

## w2 ٱلَّذِى  (107:2:2; lemma ٱلَّذِى; root —)
- ٱلَّذِى: relative pronoun; masc. singular

## w3 يَدُعُّ  (107:2:3; lemma يَدُعُّ; root د ع ع)
- يَدُعُّ: verb; imperfect (ongoing/future); 3rd person masc. singular

## w4 ٱلْيَتِيمَ  (107:2:4; lemma يَتِيم; root ي ت م)
- ٱلْ: al- (definite article; Turkish has none — definiteness must be carried otherwise or is lost)
- يَتِيمَ: noun; masc. singular; accusative
