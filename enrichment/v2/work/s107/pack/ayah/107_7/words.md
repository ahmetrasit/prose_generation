# 107:7 — words and the elements a faithful translation must carry

وَيَمْنَعُونَ ٱلْمَاعُونَ

Per word: QAC morphemes with their features in plain terms. These are the checks for the meal review: a translation keeps, drops or substitutes each element (a preposition, an attached pronoun, number, definiteness, voice, emphasis, a conjunction). Turkish may force a change; say so when it does.

## w1 وَيَمْنَعُونَ  (107:7:1; lemma مَّنَعَ; root م ن ع)
- وَ: wa- (and)
- يَمْنَعُ: verb; imperfect (ongoing/future); 3rd person masc. PLURAL
- ونَ: attached pronoun 3MP = their/them (m.pl.)

## w2 ٱلْمَاعُونَ  (107:7:2; lemma مَاعُون; root م ع ن)
- ٱلْ: al- (definite article; Turkish has none — definiteness must be carried otherwise or is lost)
- مَاعُونَ: noun; M; accusative
