# Authorized 100:1 focused comparison

The user approved this experiment after the 1:6 and 87:6 comparisons: four source families (rivayet, historical, poetry and meal), each run with corpus-only Sol high and max and memory-only Astra high and max. Sixteen fresh-context agents; Standard service; Fast disabled. The date suffix uses UTC (2026-10-07), while the user's local launch date is October 6.

All four lanes receive byte-identical 100:1 v16 r13 prose with its existing augment2 additions: 22 original paragraphs, 2,909 whitespace-delimited words. Each family has the same source-ID roster across configurations. Corpus agents also receive the established source metadata and availability limitations. Inputs, outputs and lane directories are isolated by instruction; agents may not consult earlier experiments or other agents' work. This is not an operating-system access-control claim.

Memory agents use learned knowledge only: no web, repository searches, corpus access, source/dictionary checking or helper inspection. Corpus agents may use only the bounded read-only corpus helper, including local keyword discovery. Training knowledge cannot supply their research findings or missing source positions. No new source downloads, imports or corpus rebuilds are authorized or required.

Each agent considers substantial findings and secondary connections across the whole page, writing connected Turkish blocks with explicit author/work attribution. Every paragraph receives a ledger decision. Corpus blocks carry exact locators and short supporting source anchors. Memory uncertainty is retained in prose and the ledger. The original prose is neither assessed nor edited by these researchers. The parent assembles each lane while preserving frozen bytes.

## Evaluation fixed before results

Read all sixteen outputs and ledgers. Judge distinct substantive findings, preserved author disagreements, direct lexical witnesses versus thematic parallels, accurate translator wording, attribution errors and material omissions. Deduplicate findings appearing in multiple paragraphs; length, block count and number of named authors alone do not establish quality.

Check concrete memory claims against available corpus sources, recording supported, contradicted, partly supported and unverified claims separately. Missing or inaccessible sources do not make a memory claim false. Exact quote anchors establish that a phrase is present; they do not by themselves establish that the agent's interpretation is faithful. Distinguish sources' report grades from independent authentication, and defensible translation choices from demonstrated repeated errors.

Compare high versus max within each evidence mode. Astra-versus-Sol comparisons change both model and evidence mode, so winners are workflow judgments, not isolated model-intelligence measurements. One independent run per configuration also mixes stochastic variation with effort effects. Return one recommended configuration per tested family with concrete gains/misses and costs; retain uncertainty where evidence cannot settle an attribution.
