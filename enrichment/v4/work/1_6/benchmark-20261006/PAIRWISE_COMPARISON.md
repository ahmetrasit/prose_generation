# Model, evidence and reasoning: observed 1:6 benchmark

The main result is that source retrieval and reasoning effort solve different problems. Corpus Sol recovers precise published tafsir absent from stronger memory runs. Astra develops richer remembered literature, but increasing its effort does not reliably recover a missing passage. Max in either mode is not a superset of high.

This is one independent run per family/configuration. The corpus comparison covers all 19 families at both efforts; the memory Sol max pilot has only four. Quantitative accounting covers every agent. Qualitative review uses the existing complete Astra family reviews, existing Sol/Luna memory spot reviews, every corpus ledger and source/paragraph inventory, complete modern-coherence outputs, all high-only/max-only blocks for eight other corpus families, and targeted matched paragraphs across the remaining families. It is not an exhaustive semantic audit of all 690 corpus blocks. No accuracy percentage is claimed.

## Memory versus corpus, holding Sol high fixed

Corpus Sol high costs **$16.017267 more**, or 5.23 times memory Sol high. It supplies actual passage locators, supporting source wording and locally checked author positions. Examples:

- **Classical coherence:** memory Sol has five short blocks centered on Fatiha's prayer and the opening of Baqara. Corpus high supplies 22 blocks, including Biqai's contextual explanation of 38:22, the legal commands gathered into the one path at 6:153, and the relationship between cosmic order and ethical measure in 55:7–9.
- **Bayani:** memory Sol often applies Bint al-Shati's general method. Corpus high retrieves Samarrai's specific distinctions among direct-object/ila/li guidance, his counterexamples to a rigid direct-object rule, and Bint al-Shati's distinctions among sawa, sawiyy and adl.
- **Meal:** memory Sol does not establish repeated translator patterns in the reviewed examples. Corpus high compares actual formulations and notes: Okuyan's explicit "single correct" reading of 17:9 versus DIB's superlative, the rendering of 72:16's water as water/rain/provision, and different destination choices at 10:25.
- **Modern coherence:** corpus retrieves Cuypers's exact three-piece Fatiha scheme and closing mirror. Both Astra memory efforts explicitly cannot recall his precise scheme.

Choosing memory saves retrieval cost and permits leads from works not held locally. It loses checkable source grounding and may miss a precise passage despite recognizing the author. Choosing corpus loses access to unavailable originals and remembered outside works. In modern coherence, Farahi and the required Urdu Islahi text are unavailable under the corpus rules. Missing corpus material is not a model failure or evidence that a tradition lacks a finding.

Max costs **$12.214189 more (61.7%)** for 18 additional blocks and 2,225 additional prose words. Those sizes are not measures of additional knowledge. Some added paragraphs reuse material already assigned elsewhere; some useful high material disappears.

Strong observed max gains include Cuypers's covenant reading of 5:16, the 87–88 pairing and 81:26 center; Baqillani's specific discussion of 41:30 in Fussilat's argument and derivational wordplay at 30:43; and concrete secondary classifications in wujuh. Other families show much smaller improvements or complementary outputs.

## Astra high versus max, memory

Max costs **$15.632030 more (83.1%)** across 19 families. The existing complete reviews identify substantive gains: Bint al-Shati's Beled/Asr literary precedents, broader translator narrowing patterns, early report variants, additional allusive works, historical episodes and semantic classifications. High retains unique material, including specific Duha, Mulk and translator readings. Some max coverage is a general-method application rather than recalled author tafsir.

The ten-max/nine-high saved allocation captures the strongest observed recall gains for $26.61. All-high at $18.81 remains a useful economical literature layer. All-max at $34.44 buys more leads and synthesis, but it still fails to recall Cuypers's exact Fatiha or 5:16 scheme. Memory effort does not provide verification.

## Astra versus Sol

Within memory mode, the existing matched reviews show Astra generally supplying richer, more author-specific remembered literature than Sol; Sol/Luna often supply broader methods and familiar material. Luna is competitive in several familiar hadith and translation examples and is useful as an inexpensive lead generator. None is demonstrated more accurate by those unverified memory-only comparisons.

Memory Sol high versus max is only a four-family pilot: **$0.778987 versus $1.199432**, a 54.0% increase. Hadith has the clearest additional remembered material; classical coherence has no convincing depth gain; bayani retains method/scope problems; meal expands but still does not establish consistent translator errors. This is not evidence for a completed 19-family Sol max memory workflow.

Across evidence modes, corpus Sol high ($19.80) and memory Astra high ($18.81) are close in price; corpus Sol max ($32.02) and memory Astra max ($34.44) are also close. Corpus Sol is preferable when the deliverable requires actual source pointers and source-specific findings. Astra memory is useful for broad leads, outside-corpus authors and interpretive synthesis. These comparisons change model and evidence mode together: do not attribute their differences solely to model intelligence or memory access.

## What inflated corpus cost

Corpus high accumulated **64.14M input tokens**, of which **61.84M were cached**, plus 284,579 output tokens. Corpus max accumulated **104.48M input**, **101.10M cached**, plus 503,558 output. Repeated growing contexts count at every source retrieval and writing/checking call; these are not single initial prompts.

At this run's short-context rates, high's cost is about **$4.59 uncached input + $12.37 cached input + $2.85 output**. Max is **$6.76 + $20.22 + $5.04**. Cached input accounts for roughly 62–63% of cost. Max's additional cost is therefore mostly repeated context and retrieval work, not only extra reasoning output. No request in the completed 1:6 corpus lanes triggered long-context pricing. Max can even be cheaper within a family: Imami–Mutazili was $1.47 max versus $2.03 high because usage differed.

A shorter frozen prompt alone would not remove this main cost. A bounded source packet or staged retrieval/extraction could reduce repeated contexts, but neither alternative has been benchmarked here. A shared source ledger is a plausible next experiment; its savings and ability to preserve these findings should be measured rather than assumed.

## Validation and practical limits

Both corpus assemblies passed paragraph/source/ledger checks and preserved frozen prose bytes. Parent review repaired **60 raw anchor mismatches**: 20 punctuation/spacing/diacritic variants, others shortened paraphrases/connectors or anchors below the minimum; one Cishumi classification was narrowed because its page transition was missing. Max Turkish tafsir's 21 `matched` statuses were normalized to required `written`. All repairs, original anchors and the changed prose are preserved in `PARENT_ANCHOR_REVIEW.json`. Thus final passing anchors are not presented as flawless original agent outputs.

The two scanner flags were searches confined to the agents' own output JSONL for validation, not repository/corpus discovery or another lane. Source availability, imperfect OCR, differing discovery paths and conservative no-match thresholds all affect the result. Corpus anchoring makes attribution checkable; it does not authenticate editions, independently grade hadith, or establish exhaustiveness.

The 87:6 comparison is saved separately after its corpus Sol max run completes. It compares with the existing Astra high memory run and therefore changes both effort/model and evidence mode.
